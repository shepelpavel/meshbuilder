# MeshBuilder — моделирование пропов внутри Godot

MeshBuilder превращает 3D-вьюпорт редактора Godot в инструмент моделирования: примитивы «нарисовал и
готово», правка вершин/рёбер/граней, операции над мешем, UV-редактор и палитра материалов проекта.
Без Blender, без экспорта/импорта и без выхода из редактора.

Плагин — форк **PoiBuilder** (MIT), вырезанный под моделинг пропов: убраны сплаты и роспись по граням,
экспорт PBM и ретро-пайплайн, партиклы, анимированный UV-скролл, спрайты-биллборды, пресеты времени
суток и офлайн-документация.

- **Godot:** 4.7 или новее
- **Язык:** чистый GDScript, без GDExtension, C# и нативных бинарников
- **Лицензия:** MIT (`LICENSE`)

---

## Установка

1. Скопировать каталог `addons/meshbuilder` в проект.
2. `Проект → Настройки проекта → Плагины` → включить **MeshBuilder**.
3. Внизу редактора появятся три вкладки: **MeshBuilder** (тулбар), **Materials** (палитра) и **UV Editor**.

Горячие клавиши регистрируются в `Настройки редактора → Шорткаты → meshbuilder/…` и переназначаются как
любые другие. Конфликтующие дефолты Godot плагин снимает сам и пишет об этом в Output.

## Интерфейс

Тулбар — три ряда, сгруппированные по смыслу (группы разделены вертикальными линиями):

| Ряд | Что там |
|---|---|
| 1 | режимы (Object / Vertex / Edge / Face / Texture), Move / Rotate / Scale, переключение Space, операции выделения, Auto Smooth |
| 2 | V-Snap, Soft (пропорциональная правка) и радиус, сетка с привязками, Lit / Shadow / X-Ray, операции меша (Extrude, Inset, Bevel, Subdiv, Merge, Del, Knife, Loop Cut, Connect, Bridge, Collapse, Fill Hole, Weld, Detach) |
| 3 | New Shape, N-Gon, Edit Params, объектные операции (Merge Objects, Mirror, Center Pivot, Freeze Xform, MeshBuilderize), Merge by Dist, CSG (Union / Subtract / Intersect), Trim Walls, кнопки панелей |

Панели — отдельные вкладки внизу: тулбар открыт при старте, `Materials` и `UV Editor` раскрываются
кнопками третьего ряда.

## Создание геометрии

**13 примитивов:** cube, stair, curved stair, prism, cylinder, plane, door, pipe, cone, arch, sphere,
torus, n-gon — плюс **Trim Walls** (плинтусы/молдинги по стенам).

- **New Shape** в тулбаре → выбрать фигуру → тянуть основание по любой поверхности → движение мыши
  задаёт высоту → клик подтверждает. `Ctrl` фиксирует направление, `Esc` отменяет.
- Простые фигуры (куб, призма, плоскость) подтверждаются сразу; у остальных открывается модалка
  параметров. **Edit Params** открывает её позже — пока геометрию не начали править руками.
- N-Gon рисуется контуром по кликам.
- Фигуры, протянутые от поверхности (плоскость), отрываются от неё нормальным смещением.

## Режимы и выделение

Клавиши `1` / `2` / `3` переключают вершины / рёбра / грани (`6` — Texture), `H` / `J` / `K` —
те же режимы, когда хочется обойтись без цифр. Переключение режимов конвертирует выделение.

- клик — один элемент, рамка — группа, `Shift` — добавить, `Ctrl` — убрать;
- **рёбра:** `Alt+клик` или двойной клик — петля рёбер (loop), `Shift+Alt+клик` — кольцо (ring);
- `Ctrl+I` — инверсия, `Alt+G` / `Alt+Shift+G` — расти/уменьшать выделение, `Alt+C` — компланарные,
  кнопки **Similar** и **Boundary** — похожие грани и граница;
- **V-Snap** — привязка к ближайшей вершине, **Soft** — пропорциональная правка с радиусом;
- **X-Ray** (`Alt+Z`) — полупрозрачный меш, видно и можно выбирать обратную сторону. **При выключенном
  X-Ray скрытые элементы не выбираются:** клик и рамка берут только то, что видно.

## Операции с мешем

| Операция | Клавиша | Что делает |
|---|---|---|
| Extrude | `E` | выдавливает выделенные грани/рёбра |
| Inset | `I` | вставляет грань внутрь выделенной |
| Bevel | `B` | фаска рёбер/граней/вершин (модалка с Distance и Segments) |
| Subdivide | `D` | делит грани |
| Loop Cut | `Ctrl+R` | вставляет петлю рёбер через кольцо квадов |
| Knife | кнопка | режет грань по кликам; замкнутый контур в середине грани — вырез |
| Merge Faces | кнопка | сливает выделенные грани в одну |
| Merge (Weld) | `M` | сливает выделенные вершины в центроид |
| **Merge by Dist** | кнопка | сливает все вершины ближе 1 мм по всему мешу (как в Blender) |
| Bridge / Connect / Collapse | `Shift+B` / кнопка / кнопка | мост между рёбрами, новое ребро, схлопывание |
| Fill Hole | кнопка | закрывает дырку по границе |
| Detach | кнопка | выносит выделенные грани в отдельный объект |
| Delete | `X` | удаляет по режиму: грани, рёбра (со слиянием соседей) или вершины |

**Bevel:** Distance — в метрах, максимум ограничен 49 % самого короткого ребра; Segments 1–8 скругляют
фаску. У вершинного бейвела сегментов нет (это один плоский срез), поэтому слайдер у него не
показывается. Грань с вырезом (после замкнутого ножа) перед фаской автоматически разбивается на
треугольники — иначе фаска по её рёбрам невозможна.

## Объектные операции и CSG

- **Merge Objects** — слить выделенные `MBMesh` в один, **Mirror** — зеркалить по X, **Center Pivot**,
  **Freeze Transform** — «запечь» трансформ в геометрию.
- **MeshBuilderize** — превратить `MeshInstance3D` или `CSG`-ноду в редактируемый `MBMesh`.
- **CSG Union / Subtract / Intersect** — булевы между выделенными объектами через CSG-ядро Godot.
- **Lit / Shadow** — переключить освещённость и тени у выделенных объектов.

## Материалы

Вкладка **Materials** — палитра проекта: карточки материалов и текстур (скан `res://`), `+ Add` для
файла с диска, `↺` для пересканирования.

- клик по карточке — применить материал к выделенным граням (в Object-режиме — ко всей модели);
- правый клик — **Set as Default** (материал для новых фигур, помечается ★), **Apply to Selection**,
  **Copy Path**;
- перетаскивание карточки на объект во вьюпорте тоже назначает материал.

## UV-редактор

Отдельная вкладка `UV Editor`. Каналы **UV1** (текстура) и **UV2** (лайтмапа), режимы Auto/Manual,
инструменты Move/Rotate/Scale (`W` / `E` / `R`, `F` — кадрировать выделение), снап к сетке с выбором шага.

- Проекции: **Planar**, **Box**, **Fit** в [0,1], **Unwrap** в чистую развёртку без перекрытий,
  **Lightmap** — развёртка UV2 в атлас для `LightmapGI`.
- Правка: **Flip U/V**, повороты ±90°, **Sew** / **Split** / **Collapse** / **Stitch**.
- **Texel density:** `Get` снимает плотность с выделенной грани, `Set` применяет целевую (px/м).
- **Export PNG** — сохранить UV-шаблон картинкой; **↗ Window** — вынести редактор в отдельное окно.
- Строка **Face:** — правка на уровне грани, без развёртки: `×2`, `÷2`, `Reset (1m)`, `45°`,
  Tiling U/V, Offset U/V, Angle, Flip U/V и **Tint** (вершинный цвет выделенных граней, `White` —
  сбросить). Значения подтягиваются от первой выделенной грани и применяются с undo на каждое действие.

## Сетка и привязки

Своя сетка поверх сцены: **Y** — включить/выключить привязку, `=` / `-` — мельче/крупнее деление,
`Ctrl+=` / `Ctrl+-` — размер ячейки ×2/÷2, `[` / `]` — поднять/опустить плоскость сетки, `\` — сброс
высоты. Снап работает и для новых фигур, и для перетаскивания элементов.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1` `2` `3` `6` | режимы вершин / рёбер / граней / текстуры |
| `H` `J` `K` | те же режимы (альтернатива цифрам) |
| `G` `R` `S` | Move / Rotate / Scale |
| `Shift+X` | переключить Space гизмо |
| `E` `I` `B` `D` | Extrude / Inset / Bevel / Subdivide |
| `Ctrl+R` | Loop Cut |
| `Shift+B` | Bridge Edges |
| `M` | Merge (склеить выделенные вершины) |
| `X` | удалить по режиму |
| `Ctrl+I` | инвертировать выделение |
| `Alt+G` / `Alt+Shift+G` | расти / уменьшать выделение |
| `Alt+C` | выделить компланарные |
| `Alt+L` / `Alt+R` | петля / кольцо граней |
| `Alt+Z` | X-Ray |

Все бинды меняются в настройках редактора; конфликтующие с Godot плагин снимает при первом запуске.

## Отмена и сохранение

Каждая операция — одно действие в `UndoRedo` редактора (`Ctrl+Z` / `Ctrl+Shift+Z`). Геометрия живёт в
сцене нодой `MBMesh` (это `MeshInstance3D` с мешем, собранным из данных), поэтому сохранение сцены
сохраняет и модель.

**Экспорта в файл нет:** GLB-экспортер делил диалог с PBM и ретро-пайплайном, и канал убран целиком.
Нужен файл — `ArrayMesh` сохраняется из инспектора ноды.

## Ограничения и особенности

- Работает только с `MBMesh`; обычный `MeshInstance3D`/`CSG` сначала превращается через **MeshBuilderize**.
- **Merge by Dist** сливает вершины ближе 1 мм; грани, потерявшие площадь, удаляются.
- **Bevel кромки выреза** невозможен, пока у отверстия нет стенок (ребро граничит с одной гранью) —
  сначала прорезать насквозь или выдавить внутрь.
- Вершинный бейвел — плоский срез (без сегментов); вершины на открытой кромке пропускаются с сообщением
  в верхней панели вьюпорта.
- Операция, которой нечего делать (пустое выделение, Object-режим, нулевое расстояние), сообщает причину
  в верхней панели вьюпорта на несколько секунд.
- Вершинный цвет (**Tint**) виден только в материалах, которые используют цвет вершин как albedo.

## Проверка изменений

Плагин проверяется headless-прогоном редактора и `--check-only` по скриптам; для визуальной приёмки —
обычный запуск Godot с открытой сценой.
