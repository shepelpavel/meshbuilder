# RFC 0007: Раскраска вершин и вкладка MBPaint

- Статус: implemented (2026-10-31 … 2026-11-03)
- Автор: агент (по решению владельца)
- Дата: 2026-10-31
- Влияет на: `editor/paint/mb_paint_panel.gd`, `mesh_ops/mb_paint_ops.gd`, `gui/docks/mb_material_dock.gd`,
  `core/mb_mesh_data.gd`, `meshbuilder_plugin.gd`, `docs/README.ru.md`, `docs/README.en.md`
- Выделено из RFC 0030 «MeshBuilder — редактор пропов на базе PoiBuilder» (разбит на RFC 0001–0007, 2026-11-09)

## Решение

Вершинный цвет — самый дешёвый способ разнообразить проп без новых материалов: один материал, а цвет у граней
свой. Поэтому раскраска живёт в плагине как отдельный инструмент, а цвета — в данных меша (`MBMeshData.colors`,
по позиции вершины) и уходят в `ARRAY_COLOR`, то есть видны в любом материале с `vertex_color_use_as_albedo`.

## Вкладка

1. **`VtxPaint`** (2026-10-31) — раскраска отдельной вкладкой нижней панели.
2. **`MBPaint`** (2026-11-03) — вкладка слита с палитрой материалов: палитра стала нижним блоком внутри неё
   (`paint_panel.attach_materials`), отдельного таба `Materials` больше нет (см. RFC 0002). Палитра цветов
   хранится в настройках редактора (`meshbuilder/paint/palette`, `PackedColorArray`), а не в файле проекта:
   переживает перезапуск, общая для проектов, не мусорит в репозитории.

## Инструменты

- **Режимы** — иконки Object / Vertex / Edge / Face, они же переключают режим элемента в редакторе. От режима
  зависит, что красит клик: Face — вся грань под курсором, Edge — концы ближайшего ребра, Vertex — ближайшая
  вершина, Object — только градиент.
- **Brush** (иконка, подсвечивается пока включена) — кисть в 3D-вьюпорте: тянуть ЛКМ по поверхности, `Alt` —
  стирание в белый. При переходе на другую вкладку нижней панели гаснет сама.
- **Radius (m), Strength, Spread** — числовые поля. `Spread` (по умолчанию **0**) добавляет мягкий градиент
  вокруг точки клика; на нуле красится только сам элемент, соседние грани не трогаются.
- **Fill Selected** — залить выделенные грани (неактивна, пока грани не выделены), **Fill All** — весь меш,
  **White** — сброс в белый, **Eyedropper** — режим: включить и кликнуть по грани, цвет уходит в кисть, режим
  выключается сам.
- **Палитра цветов**: `+` добавляет текущий цвет кисти, правый клик по образцу — **Edit colour…** (колор-пикер)
  или **Delete**. Пересборка ряда — `remove_child` перед `queue_free`, иначе старые свотчи ещё кадр реагируют
  на клики.

## Детали реализации

- Двойники вершин (после ножей/CSG) красятся вместе: краска идёт по позициям, а не по индексам граней.
- При первой покраске плагин сам включает **vertex colour as albedo** в материалах меша — иначе краска пишется
  в меш, но на экране не видна.
- Луч кисти и пипетки считается по треугольникам самого меша в его локальных координатах, а не по физическим
  коллайдерам: чужие и устаревшие коллизии на выбор грани не влияют.
- Каждая операция (штрих, заливка, сброс, пипетка) — шаг undo.

## Проверка

- заливка выделенного меняет ровно выделенные грани, на пустом выделении кнопка неактивна;
- штрих в режимах Face / Edge / Vertex красит соответственно грань, два конца ребра, одну вершину (с двойниками);
- `Spread = 0` не задевает соседние грани, `Spread > 0` даёт градиент;
- пипетка берёт цвет грани под кликом и выключается сама; при её включении кисть гаснет;
- палитра цветов переживает перезапуск редактора, `+` / Edit / Delete меняют её состав;
- после первой покраски в материалах меша включён `vertex_color_use_as_albedo`, и цвет виден в кадре.
