# RFC 0004: Сглаживание и контроль здоровья меша

- Статус: implemented (2026-10-31)
- Автор: агент (по решению владельца)
- Дата: 2026-10-31
- Влияет на: `editor/mb_smooth_groups.gd`, `mesh_ops/mb_mesh_ops.gd`, `editor/mb_toolbar.gd`,
  `docs/README.ru.md`, `docs/README.en.md`
- Выделено из RFC 0030 «MeshBuilder — редактор пропов на базе PoiBuilder» (разбит на RFC 0001–0007, 2026-11-09)

## Решение

Сглаживание задаётся **пометкой на рёбрах**, а не порогом двугранного угла: владелец ставит «острое» там, где
нужно, как в Blender. Плюс отдельная проверка меша, потому что булево из «грязной» геометрии возвращает пустоту
без объяснений.

## Сглаживание

- **Auto Smooth** сглаживает ВСЁ, что не помечено: порога по углу нет, весь меш идёт одной группой, а разрывают
  сглаживание только рёбра, помеченные **Sharp** (они не сбрасываются и переживают повторный прогон). Пометка
  ребра разрывает веер граней вокруг его концов, поэтому излом встаёт только на помеченном ребре, а соседние
  остаются гладкими.
- **Sharp** — пометить выделенные **рёбра** «жёсткими»; повторное нажатие на уже помеченных снимает пометку
  (снимается, если помечено ХОТЬ ОДНО выделенное ребро). Пометка хранится на ребре — парой позиций, а не
  индексов, — и сохраняется со сценой. В режиме рёбер помеченные рёбра рисуются **оранжевым** вместо голубого.
- **Flat** — обратная Auto Smooth: снимает группы сглаживания, все грани становятся жёсткими. С выделенными
  гранями — только по ним, без выделения — на весь меш.

## Здоровье меша

- **Check** — проверка меша: открытые рёбра, неманifold-рёбра, несогласованная обмотка (флипы) и
  самопересечения треугольников. Итог — строкой в баннере, а проблемные грани выделяются в граничном режиме,
  чтобы их было видно. Такой меш CSG не принимает: ядро Godot молча возвращает пустоту.
- **Fix Winding** — переворачивает треугольники, которые смотрят не в ту сторону относительно соседей
  (закрытый солид проходит общее ребро в противоположных направлениях). После неё меш снова годится для CSG;
  один шаг undo.

Рабочий порядок: **Check → Fix Winding → булев**.

## Проверка

- после `auto_smooth` в каждом узле ровно одна нормаль; пометил ребро — ровно две в обоих его концах;
- `Check` на кубе даёт нули по всем счётчикам, на вывернутой грани — попадание во флипы;
- `Fix Winding` не трогает здоровый меш и делает вывернутый замкнутым;
- после булева на вылеченном меше получается геометрия, а не пустой бейк.
