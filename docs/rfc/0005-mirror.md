# RFC 0005: Зеркальное моделирование — Mirror Model и Apply Mirror

- Статус: implemented (2026-10-30)
- Автор: агент (по решению владельца)
- Дата: 2026-10-30
- Влияет на: `core/mb_mesh.gd`, `core/mb_mesh_data.gd`, `mesh_ops/mb_mesh_ops.gd`, `editor/mb_toolbar.gd`,
  `meshbuilder_plugin.gd`, `docs/README.ru.md`, `docs/README.en.md`
- Выделено из RFC 0030 «MeshBuilder — редактор пропов на базе PoiBuilder» (разбит на RFC 0001–0007, 2026-11-09)

## Решение

Моделить симметричный проп вдвое быстрее, если отражать половину «на лету», как модификатором Mirror в Blender.
Данные меша при этом хранят только половину, отражение собирается при отрисовке; когда нужно отражение как
настоящая геометрия — его запекают одной кнопкой.

## Mirror Model (2026-10-30)

Живое зеркало: данные хранят половину, отражение собирается при рендере (вершины, нормали, UV, тангенсы,
коллизия), данные не меняются. Клик по кнопке — вкл/выкл, **Shift+клик** — ось X / Y / Z. Один шаг undo.
Настройка живёт в данных меша (включено/ось) и сохраняется вместе со сценой, в грани она не пишется.

## Apply Mirror (2026-10-30)

Тумблер. Нажал — отражение запекается в реальные грани с флагом `mirror_copy`, половина остаётся
редактируемой (модификатор выключается); нажал повторно — запечённые грани удаляются, и половина снова уходит
живому зеркалу. Повторное запекание каждый раз строит копию по текущей половине, поэтому дубликаты не копятся,
а правки половины перезапекаются.

Копия наследует всё от исходной грани: форму контура (квад остаётся квадом), UV, поворот/масштаб тайлинга,
группу сглаживания и материал. Состояние тумблера читается по наличию граней с `mirror_copy` — отдельного
флага нет, поэтому переживает сохранение сцены.

Выделение после запекания сбрасывается.

## Проверка

- половина без живого зеркала рендерится как половина; включил — появилось отражение, данные не изменились
  (число позиций в `MBMeshData` прежнее);
- Shift+клик меняет ось и отражение перестраивается по ней;
- Apply Mirror → грани с `mirror_copy` есть, повторное нажатие → их нет, живое зеркало снова включено;
- у запечённой копии тайлинг UV и материал совпадают с оригиналом.
