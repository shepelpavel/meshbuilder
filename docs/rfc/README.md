# RFC: решения по плагину

Решения, которые меняют поведение или устройство плагина, оформляются документом до реализации: сначала RFC,
потом код. Мелкие фиксы и правки UI без нового решения идут коммитом.

## Файлы

- `NNNN-краткое-имя.md` — четыре цифры, номер сквозной в этом репозитории и не переиспользуется.
- Шапка: `- Статус:` (`draft` → `accepted` → `implemented`; `superseded` — если решение отменено другим RFC),
  автор, дата, «влияет на» (файлы/разделы доков), «выделено из» при разбиении.
- Реализованный RFC не переписывается: актуализация — новым разделом «Правка (дата)» или новым RFC,
  история сохраняется.

## Статусы

- `draft` — обсуждается, кода ещё нет.
- `accepted` — согласовано, можно реализовывать.
- `implemented` — в коде; в документе есть «Итог реализации» (что сделано, что осталось, грабли).
- `superseded` — заменён другим RFC (в шапке указывается каким).

## Состояние на 2026-11-09

- `plugin.cfg` → `version="0.2.4"`; 50 скриптов `.gd`, 2.4 МБ без `.git` и `dist`; Godot 4.7.1, чистый GDScript.
- Три вкладки нижней панели: `MeshBuilder` (тулбар), `UV Editor`, `MBPaint` (раскраска + палитра материалов).
- Проверка в одноразовом тестовом проекте (копия аддона + `project.godot` с включённым плагином):
  `--check-only --script` по всем 50 `.gd` — 0 ошибок; headless-запуск редактора — ошибок нет, единственная
  строка про плагин `[MB/mesh_ops] WARN: Materials: no MBMesh selected` (штатная подсказка панели на старте).
- В `README.md` и `docs/README.ru.md`/`docs/README.en.md` выпиленные вкладки (`Materials`, `VtxPaint`) как
  отдельные не упоминаются — грепом по старым именам в этих трёх файлах ноль.
- **Грабли проверки:** `--check-only` до первого прогона редактора валится по почти каждому файлу
  (`Could not find type "MBMeshData"` / `Could not find base class "MBCommand"`) — это пустой кэш глобальных
  классов (`<проект>/.godot/global_script_class_cache.cfg`), а не ошибки кода. Порядок:
  `godot --headless --path <проект> -e --quit` → потом проверка скриптов.

## Что выпилено осознанно

Не возвращать без нового RFC: экспорт в файл (PBM/ретро/GLB), сплаты и роспись по граням, партиклы,
анимированный UV-скролл, спрайты-биллборды, пресеты времени суток, собственная сетка, примитив `trim`,
операция `Collapse`.

## История документов

- До 2026-11-09 все решения по плагину лежали одним RFC 0030 «MeshBuilder — редактор пропов на базе PoiBuilder»
  (написан в репозитории игры, в коммиты не попал, удалён из индекса там; текст восстановлен из объектной базы —
  `git fsck --no-reflogs`, dangling-блоб). 2026-11-09 он перенесён в этот репозиторий и разбит на RFC 0001–0007
  без потери информации; сам 0030 после разбиения удалён. В репозитории игры RFC не возвращать: плагин оттуда
  убран, а номер 0030 там занят другим RFC («Поза лазания по точкам хвата»).
- Куда переехали разделы 0030:

| Раздел 0030 | Куда |
|---|---|
| Проблема, Альтернативы, Предложение, Последствия, Checklist | 0001 |
| Вырезание апстрима, переименование `pb_*`→`mb_*`, чистка мёртвого, Time of Day, экспорт в файл | 0001 |
| Тулбар и панели в нижний док, палитра вместо «Material & UV», высота вкладок, баннер вместо Output, горячие клавиши, крах accesskit | 0002 |
| Tunnel/Subdivide/Fill, Collapse, нож, Merge by Distance, CSG, пикинг и X-Ray, все грабли bevel | 0003 |
| Auto Smooth / Sharp / Flat, Check / Fix Winding | 0004 |
| Mirror Model, Apply Mirror | 0005 |
| Палитра меша без скана `res://`, строка «Face:», тинт граней, удаление Shapes и спрайт-инструмента | 0006 |
| Вкладка `VtxPaint` → `MBPaint`, палитра цветов в `EditorSettings`, `MBMeshData.colors` | 0007 |
| Состояние 0.2.4, проверка скриптов, список выпиленного | этот файл |
| Листинг `dist/listing.md` под 0.2.4, `.uid` для двух скриптов | этот файл |

- RFC 0008–0010 в разбиении 0030 не участвовали: они собраны отдельным проходом по истории работ
  (2026-11-09), потому что в 0030 эти системы были одной строкой. Источники — коммиты репозитория и принятые
  по ходу отладки решения: CSG (preflight-проверки, диагностика пустого бейка, undo резца), X-Ray и выбор
  скрытых элементов, модель данных меша (треугольники в грани, дубли позиций, sharp-рёбра парами) — плюс
  уточнения в 0002 (модалки, версия только в `plugin.cfg`) и 0004 (история перехода Sharp с граней на рёбра).
- **Найденное расхождение при этом проходе:** `docs/README.ru.md` и `docs/README.en.md` продолжали обещать
  авторазворот subtract (`cutter − target`), которого в коде нет с 275d030 (2026-10-31) — исправлено на
  диагностику пустого бейка; тот же неверный абзац поправлен в скилле `godot-mcp-authoring`.

- 2026-11-09 в тот же заход: листинг `dist/listing.md` переписан под 0.2.4 (13 примитивов, палитра выделенного
  меша, три вкладки с `MBPaint`, Check / Fix Winding, Mirror Model, Merge by Distance, привязка к сетке Godot,
  zip 0.2.4 на 293 файла), а `.uid` добавлены к `editor/paint/mb_paint_panel.gd` и `mesh_ops/mb_paint_ops.gd` —
  теперь `.uid` есть у всех 50 скриптов.
