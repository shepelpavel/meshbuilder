# AGENTS.md

Плагин редактора Godot: моделирование пропов прямо в 3D-вьюпорте — примитивы, правка вершин/рёбер/граней,
операции меша, UV-редактор, булевы через CSG. Форк PoiBuilder (MIT), урезанный до моделирования.

Репозиторий — **источник правды**: в проекты плагин ставится копией каталога `addons/meshbuilder/`.
В игре «Город из домов» он больше не вендорится (плагин оттуда убран, владелец моделирует в Blender).

## Что читать первым

- `docs/rfc/README.md` — индекс решений: RFC 0001 (зачем форк и что вырезано), 0002 (UI и вкладки),

## Структура

| Каталог | Что там |
|---|---|
| `meshbuilder_plugin.gd` | входная точка `EditorPlugin`: монтирует вкладки, диспетчер операций, оверлеи, undo |
| `core/` | данные меша без редактора: `MBMeshData`, `MBFace`, `MBEdge`, топология, UV-проекции |
| `mesh_ops/` | операции над данными: extrude/inset/bevel/knife/CSG/слияние, `MBPaintOps` |
| `shapes/` | генераторы примитивов (`MBShapeFactory` — единственный список типов) |
| `commands/` | undo-команды (`MBCommand` — снапшот данных меша) |
| `editor/` | редакторная часть: сессии, выделение, пикинг, гизмо, тулбар, горячие клавиши; `editor/uv/`, `editor/paint/` |
| `gui/` | доки и оверлеи во вьюпорте |
| `materials/` | материал по умолчанию, подготовка материалов, текстура-шахматка |
| `icons/` | иконки тулбара и панелей (16×16, серый корпус `#8fa3b8`, акцент `#4fb3d9`) |
| `debug/` | логгер и служебные проверки |
| `docs/rfc/` | решения (нумерация сквозная в этом репо) |
| `dist/` | сборки для стора и текст листинга — **в gitignore**, в коммиты не едет |

`class_name` — `MB*`, файлы — `mb_*.gd`, один уровень смысла: `editor/uv/mb_uv_canvas.gd` — ок, глубже не надо.
Стиль — `.editorconfig`: табы, LF, финальный перевод строки; в `.md` — 2 пробела.

## Команды

В репозитории нет `project.godot` (это аддон), поэтому проверка идёт в одноразовом тестовом проекте.
Путь к Godot 4.7 держать в переменной (у владельца он не в `PATH`).

```bash
GODOT=/path/to/godot
TEST=/tmp/mb-check

rm -rf "$TEST" && mkdir -p "$TEST/addons"
rsync -a --exclude '.git*' --exclude 'dist' --exclude '*.md' ./ "$TEST/addons/meshbuilder/"
printf 'config_version=5\n\n[application]\nconfig/name="mbcheck"\n\n[editor_plugins]\nenabled=PackedStringArray("res://addons/meshbuilder/plugin.cfg")\n' > "$TEST/project.godot"

# 1) первый прогон редактора: собирает кэш глобальных классов и импортирует иконки
"$GODOT" --headless --path "$TEST" -e --quit

# 2) проверка всех скриптов (после шага 1)
for f in $(cd "$TEST" && find addons/meshbuilder -name '*.gd'); do
  "$GODOT" --headless --path "$TEST" --check-only --script "res://$f" || echo "FAIL $f"
done
```

**Грабли:** без шага 1 `--check-only` сыпет `Could not find type "MBMeshData"` / `Could not find base class
"MBCommand"` почти по всем файлам — это пустой кэш классов (`$TEST/.godot/global_script_class_cache.cfg`),
а не ошибки кода. Сначала редактор, потом проверка.

Штатный лог запуска содержит одну строку вида `[MB/mesh_ops] WARN: Materials: no MBMesh selected` —
это подсказка панели, не ошибка.

Живую проверку UI делать в редакторе (MCP `godot-ai`, см. скилл `godot-mcp-authoring`), а не только headless:
панели, тулбар и оверлеи проверяются глазами. Правки — в изолированной копии проекта, не в чужом проекте.

## Правила

- **Версия — только в `plugin.cfg`.** Дублей версии в коде нет, не заводить.
- **Новая операция — четыре точки правки** (пропущенная = кнопка невидима/мертва): `_make_op_button(...)`
  в `editor/mb_toolbar.gd` → `_op_buttons["op_id"]` в списке своего ряда в `_update_row_layout()` →
  `disabled` в обновлении контекста (по режиму и выделению) → ветка в диспетчере `_on_operation_requested`.
  В `_perform_*`: снапшот `MBCommand.copy_mesh_data()` до и после, `UndoRedo.create_action`, `mesh.rebuild()`.
- **Горячие клавиши — только в `editor/mb_actions.gd`** (одна таблица `ACTIONS`, регистрация в
  `EditorSettings` как `meshbuilder/<id>`). Отдельных `_input`-биндов по файлам не заводить.
- **Пользователю — баннер, а не Output.** Итог операции/ошибка идут в `_op_hint()` (панель над вьюпортом);
  Output владелец не читает. Баннер троттлить, если зовётся из `_process`.
- **Каждая правка геометрии/цвета — один undo-шаг.** Данные меша меняются через снапшот, а не «вживую».
- **Документация — в той же задаче.** Изменил поведение → правь `docs/README.ru.md` (RU-first), затем
  `docs/README.en.md`, и `README.md`, если изменился список возможностей. Старые имена вкладок/операций
  вычищать грепом до нуля.
- **`.uid` рядом со скриптом едет в репо.** Добавил `.gd` — открой проект в редакторе и закоммить
  появившийся `*.gd.uid` (на 2026-11-09 `.uid` есть у всех 50 скриптов).
- **Выпиленное не возвращать без нового RFC:** экспорт в файл (PBM/ретро/GLB), сплаты и роспись по граням,
  партиклы, анимированный UV-скролл, спрайты-биллборды, пресеты времени суток, собственная сетка,
  примитив `trim`, `Collapse`.
- **Листинг магазина и превью (`dist/listing.md`, `dist/thumbnail.png`) — отдельный гейт:** править только
  по прямой просьбе владельца. Листинг приведён к 0.2.4 (13 примитивов, палитра меша, `MBPaint`,
  Check / Fix Winding); после каждой смены возможностей он снова отстаёт — расхождение называть.
- **Коммиты — Conventional Commits, по явной команде владельца.** Сообщения по-русски, назывным оборотом
  (`feat(paint): …`, `fix(ui): …`, `docs: …`, `chore(release): …`).
- **Комментарии в коде — только «почему»;** пояснительных «что делает» не добавлять.

## Грабли (проверены на этом коде)

- **Вкладка нижней панели открывается нулевой высоты.** `ScrollContainer` сообщает минимальную высоту 0,
  поэтому панель подгоняется под отступы и схлопывается. Лечение — `_give_scrolled_panel_height(host,
  content, fallback)` при монтировании КАЖДОЙ вкладки; меру брать у содержимого, `fallback` — нижняя
  граница (60–70 px для узкой панели, 230+ для слитой). Проверять тремя кругами переключения вкладок.
- **Отдельной вкладки `Materials` нет.** Палитра материалов пристёгнута внутрь `MBPaint`
  (`paint_panel.attach_materials`), кнопка `Materials` в тулбаре раскрывает `MBPaint`. Второй
  `add_control_to_bottom_panel` на палитру заведёт пустую вкладку-дубль.
- **`EditorSettings` — хранилище состояния плагина:** бинды `meshbuilder/<id>`, палитра цветов
  `meshbuilder/paint/palette`. В тестовом проекте всё дефолтное — сбрасывать настройки редактора не нужно.
- **Данные меша дублируют позиции на грань** (`MBMeshData.positions`), поэтому связность ищется по
  квантованным координатам, а не по индексам. Новый код, который «правит вершину по индексу», сдвинет одну
  копию и ничего не изменит.
- **`CSGShape3D.bake_static_mesh()` отдаёт вершины в ЛОКАЛЬНЫХ координатах узла** — второй раз трансформ
  узла применять нельзя, рез уедет.
- **Падение редактора при перетаскивании панелей — не плагин** (движковый accesskit, `InterfaceNotFound`).
  Обход — `interface/accessibility/accessibility_support = 2` или флаг `--accessibility disabled`; сам
  плагин лейаут редактора не трогает (`_setup_ideal_dock_layout` удалён).
- **Удалять `MeshInstance3D`/CSG-дерево — только через `queue_free` комбайнера**, без `free()` детей:
  двойное освобождение убивает процесс SIGABRT без внятного стектрейса.
- **Новый скрипт на диске не виден редактору** до скана: в живом редакторе MCP — `filesystem_manage(op="scan")`,
  иначе `--check-only` видит класс, а редактируемая сцена — нет.
- **После `git mv`/удаления скриптов Godot ищет старые пути** — виноват кэш `.godot/uid_cache.bin`: скан его не
  чинит, а редактор при автосейве пишет старые uid→path обратно. Лечение: закрыть редактор, удалить
  `.godot/uid_cache.bin`, открыть проект заново (кэш пересобирается из `*.uid`). Проверка — лог запуска без
  `invalid UID` и `ProjectSettings.get_global_class_list()` с новыми путями.
- **Плагин можно уронить настройкой редактора, а не кодом:** перетаскивание панелей валит процесс в
  `accesskit_unix … InterfaceNotFound` (SIGABRT). Лечится флагом `--accessibility disabled` или строкой
  `interface/accessibility/accessibility_support = 2` в настройках редактора — POSIX
  `~/.config/godot/editor_settings-4.<N>.tres`, Windows `%APPDATA%\Godot\editor_settings-4.<N>.tres`.

## Релиз

1. Поднять `version` в `plugin.cfg`.
2. Собрать пакет: zip с префиксом `addons/meshbuilder/…`, без `.git*`, `dist/`, `docs/`, `*.md`.
3. Прогнать проверку из раздела «Команды» (headless-редактор + `--check-only` + живой редактор на вкладки).
4. Положить сборку в `dist/meshbuilder-<ver>.zip` (каталог в `.gitignore`, в коммит не попадает).
5. Публикация в Godot Asset Store и правка листинга — только по отдельной команде владельца.
